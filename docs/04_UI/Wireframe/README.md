# Bản Thiết Kế Khung Giao Diện (Wireframe)

Thư mục lưu trữ bản vẽ phác thảo cấu trúc giao diện (Low-fidelity wireframes):

- `WF_RoomGrid.png`: Sơ đồ trạng thái phòng theo tầng (Màu sắc: Trống, Có khách, Đã đặt, Đang dọn).
- `WF_BookingModal.png`: Khung biểu mẫu tạo đơn đặt phòng nhanh.
- `WF_InvoicePrint.png`: Khung mẫu in phiếu hóa đơn thanh toán cho khách.
