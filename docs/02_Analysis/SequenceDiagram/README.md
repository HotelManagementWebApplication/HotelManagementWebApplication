# Biểu đồ Tuần tự (Sequence Diagram)

Thư mục lưu trữ biểu đồ tuần tự mô tả sự tương tác giữa Actor, UI, Controller, Service và Database:
1. **SD_Login**: Quá trình gửi thông tin đăng nhập, xác thực qua Spring Security, sinh JWT token và trả về client.
2. **SD_Booking**: Quá trình kiểm tra phòng trống, tạo bản ghi đặt phòng, khóa tạm phòng và sinh mã đặt phòng.
3. **SD_CheckOut**: Quá trình tổng hợp chi phí phòng, dịch vụ, tạo hóa đơn và thanh toán.
